# Wolf's Vault — Universal Card Redesign Archive

This archive contains the implementation brief and before/after visual references for redesigning Wolf's Vault account cards in the existing **web application**.

## Local design inputs

The supplied brief and reference images include personal account details and
are intentionally excluded from Git. Public browser evidence uses invented
records instead.

- `AGENT_BRIEF.md` — developer-agent brief, design requirements, implementation guidance, and acceptance checklist.
- `approved-redesign.png` — visual target showing contextual icons, clearer information hierarchy, and compact footer actions.
- `original.png` — screenshot of the existing retirement account card layout.

## Implementation documentation

- `IMPLEMENTATION.md` — delivered scope, changed files, validation results, and limitations.

## Scope

Implement a reusable, responsive **web** card design across applicable Wolf's Vault sections. Preserve existing data, business logic, HomeBank integration, navigation, edit/document functionality, and delete safeguards.

Start with `AGENT_BRIEF.md` and use the two images as visual references.

The shared redesign is implemented across all record sections, search previews,
beneficiary records, and personal-content cards. See [implementation notes](IMPLEMENTATION.md)
and [browser evidence](../screenshots/record-cards/README.md).
